# Bird Species Observation Analysis Dashboard

## Files
- app.py
- Bird_Monitoring_Data_FOREST_CLEANED.xlsx
- Bird_Monitoring_Data_GRASSLAND_CLEANED.xlsx
- requirements.txt

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

The dashboard contains 24 interactive charts, filters, KPI cards, a dataset preview, and CSV download.
